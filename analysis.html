Data Analysis


From Raw Field Data to a Reproducible and Explainable Analysis

DATA ANALYSIS PROCESS OVERVIEW

DATA ENGINEERING

  • pandas imported both Excel sources and created raw, clean, and coded tables.
  • Automated checks flagged ineligible cases, rapid completion, duplicate IPs/response patterns, missing values, and straight-lining.
  • Multi-select items were converted to 0/1 variables; Likert scale responses retained ordered 1–5 coding.

STATISTICAL ANALYSIS

  • Descriptive outputs: means, standard deviations, Top-2-box rates, Top-3 selection rates, and multi-response percentages.
  • Spearman correlations tested relationships among online-shopping frequency, purchase intention, explanation-based trust, and tool-use intention.
  • Mann–Whitney or Kruskal–Wallis tests compared relevant consumer groups without assuming normality.

GAP & VISUAL ANALYTICS

  • NumPy normalized mean importance to a 0–1 scale: (mean − 1) / 4.
  • Attribute Gap = normalized consumer importance − product-information coverage.
  • seaborn and Plotly produced ranked bars, heatmaps, group comparisons, and interactive figures.

EXPLAINABLE MATCHING

  • Consumer preferences and product features were encoded as comparable vectors.
  • Budget/category filters were applied before weighted scoring and cosine similarity ranked top 3 products.
  • The system reports the highest-contributing attributes as human-readable recommendation reasons.

FINAL DATA GRAPHS

KEY FINDING OF THE DATA ANALYSIS

The central problem is an evidence gap, not a lack of interest. Consumers prioritize safety, quality, trust, traceability, and certification, yet these attributes are least consistently documented.
